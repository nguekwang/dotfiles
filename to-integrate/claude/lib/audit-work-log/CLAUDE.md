# Audit Work Log

The material the `/audit-work-log` command (`.claude/skills/audit-work-log/SKILL.md`) reads and runs. Nothing here runs on its own.

| Path | Role |
| --- | --- |
| `references/` | How to find the needed columns in a pasted task list or raw log, whatever the export's layout |
| `scripts/` | `find-gaps.py`, the arithmetic that locates untracked time in a raw log against the work window |
