# Meeting Docs

The protocol and reference documents the meeting commands read.

| Path | What it holds |
| --- | --- |
| `minutes/` | The meeting protocol, the minutes template, the start and end prompts, and every meeting's minutes |
| `review/` | The review lens and the review workflow for a meeting branch |
| `runbooks/` | Setting up the meeting commands on `PATH` |
| `playbooks/` | The presentation playbook the proposal commands follow |
| `architecture/` | The wrapper and implementation split of the shell scripts |
| `organization-model.md` | The AI-Org model: the repository as a company, each agent a role |
