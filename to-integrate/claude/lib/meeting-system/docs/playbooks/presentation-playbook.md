# Presentation Playbook

## Objective

Create proposals that are easy to approve, easy to challenge, and easy to execute.

## Default Deck Structure

1. Decision summary
2. Context and objective
3. Key market insight
4. Options compared
5. Recommended model
6. KPI and impact estimate
7. Execution plan
8. Risks and mitigations
9. Open questions

## Slide Rules

- Put the recommendation on the first slide.
- Keep one decision per slide.
- Separate facts, assumptions, and recommendations.
- Use tables for competitor or option comparison.
- Show the tradeoff, not only the preferred answer.
- End with explicit next actions and owners.

## Feedback Incorporation Rules

- Apply active `feedback_rules` before writing slide copy.
- Prefer normalized rules over raw historical feedback.
- If multiple rules conflict, higher-priority rules win and the conflict is logged.
- If a known user preference is intentionally not applied, explain why in speaker notes or run metadata.

## Quality Gate

- Is the recommendation explicit?
- Are the top alternatives compared?
- Are sources or assumptions visible for each major claim?
- Can the audience decide what to do next from this deck alone?
