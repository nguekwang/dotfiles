## このマシンに npm は無く、グローバルな JS 製 CLI は bun で入れ替える

- 種別: 既存スキルの修正
- 対象: environment-assumptions
- 根拠: ユーザー自身が最後に実行したコマンド (20:21) — `bun install -g @anthropic-ai/claude-code@2.1.251`。セッション中に `claude update` が失敗した原因も「npm が未インストール（bun のみ）で、アップデータが npm を呼ぶ」ことだった。
- 提案: environment-assumptions のツール前提に、Node/JS 系パッケージマネージャの項を追記する。具体的な文面案:
  - 「JavaScript 製のグローバル CLI はこのマシンでは **bun** だけで管理される。`npm` / `yarn` / `pnpm` はインストールされていない。`npm install -g` や、内部で npm を呼ぶ自己更新コマンド（例: `claude update`）は失敗する。」
  - 「インストール・更新は `bun install -g <pkg>@latest`、バージョン固定・ロールバックは `bun install -g <pkg>@<version>` を使う。npm を新規に入れて解決しようとしない。」
  - 併せて、同スキルの「設定の実体の在処」に1行追加: 「`~/.claude/settings.json` は本リポジトリの `.claude/settings.json` へのシンボリックリンク。ユーザーグローバル設定への編集はトラッキング対象ファイルへの変更として `git status` に現れる（このセッションで実機確認）。」
