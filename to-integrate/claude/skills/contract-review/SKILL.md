# Contract Review Checklist

契約書を作成するとき、およびレビューするときに確認する項目。

使い方は次の通り。該当する契約種別の節まで一般項目を順に当て、未確認の項目は
「未確認」として明示的に残す。チェックが付かない項目を黙って飛ばさない。契約書の
抜け漏れは締結後に是正できないため、判断できない項目はユーザーに差し戻す。

出力の体裁は `prose-style` と `figure-rendering` に従う。契約は日本語で書くため
`language-conventions` の日本語の表記規則も適用する。

## 契約の基本情報

- [ ] 契約の目的・内容を明確にしている
- [ ] 契約当事者（名称・代表者・住所）を確認している
- [ ] 契約の開始日と終了日を決定している
- [ ] 契約形式（書面・電子契約など）を決めている

## 契約内容の確認

- [ ] 提供サービス・商品の内容を詳細に記載している
- [ ] 納期・納品物の仕様を明確にしている
- [ ] 成果物の所有権・著作権の帰属を明記している
- [ ] 秘密保持条項を含めている
- [ ] 個人情報の取り扱いについて記載している

## 契約金額と支払い条件

- [ ] 契約金額を明確に記載している
- [ ] 消費税の扱いを明記している
- [ ] 支払い方法（銀行振込・クレジットカードなど）を決定している
- [ ] 支払い期日・期限を指定している
- [ ] 請求書の発行方法と時期を決めている
- [ ] キャンセル料・違約金がある場合は金額を明記している

## 責任と保証

- [ ] 各当事者の責任範囲を明確にしている
- [ ] 免責事項を記載している
- [ ] 瑕疵担保責任の期間を定めている
- [ ] 保証内容（あれば）を明記している
- [ ] 保険加入の要件がないか確認している

## 契約の解除・終了

- [ ] 契約解除の理由と手続きを明記している
- [ ] 解除予告期間を定めている
- [ ] 契約終了時の措置（データ返却・機密情報の処理など）を記載している
- [ ] 契約終了後も続く義務がないか確認している

## 紛争解決

- [ ] 準拠法を明記している（日本法か外国法か）
- [ ] 管轄裁判所を指定している
- [ ] 調停・仲裁の条項がないか確認している
- [ ] 紛争解決の手順を明記している

## 法令遵守

- [ ] 関連する法律・規制に準拠しているか確認している
- [ ] 業界固有のルール（金融、医療など）に対応しているか確認している
- [ ] 個人情報保護法（APPI）への対応を確認している
- [ ] 下請法の対象となるか確認している（必要に応じて対応）

## 契約書の形式

- [ ] 署名欄に日付・名義・押印（電子署名）スペースがある
- [ ] 契約当事者の数分だけコピーを作成する
- [ ] 原本と控えの区別が明確である
- [ ] ページ番号を記載している
- [ ] 訂正がある場合は署名欄で訂正印を押している

## 承認と署名

- [ ] 契約内容について当事者間で合意がとれている
- [ ] 社内承認（決裁）をとっている
- [ ] 契約権限のある者が署名している
- [ ] 電子契約の場合はシステムの利用規約を確認している
- [ ] 両当事者が署名・押印をしている

## 記録と保管

- [ ] 契約書の原本を大切に保管している
- [ ] コピーを複数保管している
- [ ] 契約管理システムに登録している
- [ ] 契約内容を関係者に周知している
- [ ] 契約期間中に内容を確認できる体制がある
- [ ] 契約終了後も必要期間保管している

## 特殊な契約での追加確認項目

### NDA（秘密保持契約）の場合

- [ ] 秘密情報の定義が明確である
- [ ] 秘密保持期間を定めている
- [ ] 例外事項（公開情報など）を記載している
- [ ] 違反時の損害賠償について明記している

### 雇用契約の場合

- [ ] 職務内容を明確にしている
- [ ] 給与・手当の金額と支払い時期を明記している
- [ ] 労働時間・休日を定めている
- [ ] 福利厚生について記載している
- [ ] 退職金の有無と計算方法を明記している
- [ ] 競業避止義務がある場合は期間と地域を限定している

### 委託契約の場合

- [ ] 委託内容と責任分界点を明確にしている
- [ ] 納品物の検収基準を定めている
- [ ] 報告義務を明記している
- [ ] 下請けへのさらなる委託が許可されるか確認している

### 変更契約の場合

- [ ] 元契約との関係を明確にしている
- [ ] 変更内容を具体的に記載している
- [ ] 変更前の条項で残るものを明記している
- [ ] 変更前後の契約の矛盾がないか確認している

## 最終確認

- [ ] 契約内容全体を読み直している
- [ ] 誤字脱字がないか確認している
- [ ] 数字や金額に誤りがないか確認している
- [ ] リンク（参考資料など）が正しいか確認している
- [ ] すべての空欄が埋められているか確認している
- [ ] 法務担当者の確認をとっている
