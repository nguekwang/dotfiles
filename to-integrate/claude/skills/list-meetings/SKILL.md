# /list-meetings

Run `.claude/lib/meeting-system/bin/list-meetings` (or `.claude/lib/meeting-system/scripts/utils/list-meeting-worktrees.sh`) and present the active meeting branches and any linked git worktrees, noting which one (if any) matches the current checkout.
