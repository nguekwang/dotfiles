# .github/ISSUE_TEMPLATE

The issue form. `task.yml` puts `Why` first, marks `Why`, `What`, and
`Done when` required, and sets the title form (verb infinitive + object);
`config.yml` turns blank issues off. The form's rules are stated in the
`issue-tracking` skill, "Issue Schema"; the workflow in `../workflows/` closes
an issue that does not follow them.
